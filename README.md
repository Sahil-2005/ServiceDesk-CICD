# CI/CD Pipeline for an IT Service Desk Portal

## Project Overview
A web-based IT Service Desk Portal developed as a 15-week DevOps project. The application will support ticket creation, viewing, updating, searching, role-based status workflows, and a summary dashboard.

## Technology Stack
- Backend: Java 17, Spring Boot, Maven
- Frontend: React, Vite
- Database: MySQL 8.4
- DevOps: Git, GitHub, Jenkins, Docker, Selenium, Ansible

## Project Structure
- `backend/` - Spring Boot REST API
- `frontend/` - React user interface
- `docker/` - Docker and deployment configuration
- `docs/` - Project planning, requirements, and architecture documents

## Project Status
Initial workspace and local development environment setup.
